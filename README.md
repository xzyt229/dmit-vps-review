## 什么是高性能VPS？为什么网络线路比配置更重要

**高性能VPS**，指的是在计算资源（CPU、内存、磁盘IO）和网络传输两个维度同时达到较高水准的云服务器。

对于国内用户，"高性能"里最容易被忽视的部分，是从服务器到国内用户之间的网络路径质量。

普通163线路：国内省际用的普通骨干网，晚高峰拥堵严重，延迟飙升，丢包率高。

CN2线路：电信下一代承载网（CNCN缩写而来），分GT和GIA两档。CN2 GIA（Global Internet Access）是最高端的，省际和国际出口都走专用59.43节点，即使晚上20点—23点高峰期也极少拥堵，延迟稳定、丢包率低。

简单说：**同样1核2G的服务器，走CN2 GIA的体验可以比普通线路好3—5倍**。

DMIT的产品正是建立在这套逻辑上的。据来自VPS测评网站VPS1352的横向对比，在速度维度上的排名是"DMIT > 搬瓦工 ≈ GigsGigs > HostDare"，DMIT排名第一，代价是价格也更高。
